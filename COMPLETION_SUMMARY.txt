================================================================================
  TROUBLESHOOTING QUICK REFERENCE
================================================================================

Frontend won't start?
  → Check Node.js version (18+ required)
  → Try: npm install --legacy-peer-deps
  → Verify: NEXT_PUBLIC_API_URL in .env.local

Frontend can't connect to backend?
  → Verify backend is running (http://localhost:3001)
  → Check NEXT_PUBLIC_API_URL value
  → Check browser console for CORS errors

Backend won't start?
  → Verify PostgreSQL is running
  → Check DATABASE_URL in app/.env
  → Run: npm --prefix app run migrate

Database errors?
  → Verify PostgreSQL is accessible
  → Check connection string
  → Check: npm --prefix app run migrate:check

Port conflicts?
  → Frontend: different port in next.config.js
  → Backend: different PORT in app/.env
